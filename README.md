# 林深处 · 黄昏森林原木小屋（Phase 3d：提亮补光 + 绘制瘦身）

单页 WebGL 场景：黄昏时分，森林深处的小木屋。three.js + TypeScript + Vite。
**零外部媒体依赖** — 全部纹理 canvas 程序生成，音频将用 Web Audio 合成（无下载、无 API）。

## 运行

```bash
npm install        # 建议国内镜像：--registry=https://registry.npmmirror.com
npm run dev        # 开发预览（默认 http://localhost:5173）
npm run build      # tsc --noEmit && vite build
npm run preview    # 预览构建产物
```

## 操作

- 鼠标/触摸拖拽 — 360° 环绕；滚轮/双指 — 推拉（2.2–45m）
- 双击 — 定格观察目标；键盘 `1-4` — 黄昏/蓝调/夜晚/黎明 预设
- 右上 ⚙ — **光影面板**：12 滑杆（太阳方位/高度/强度/色温、雾、曝光、炉火、窗灯、炊烟、颗粒、暗角、辉光）+ 4 预设 + 阴影档位 + 恢复默认；参数自动存 localStorage；打开时焦点进面板、Esc 关闭回把手

## URL 参数

| 参数 | 说明 |
|------|------|
| `?t=秒` (0–86400) | 一天中的时刻，clock 时钟模式 |
| `?light=dusk\|blue\|night\|dawn` | 光线预设 |
| `?q=low\|medium\|high\|ultra` | 画质档（默认自动） |
| `?shot=1` | 截屏确定性模式（无漂移、遮罩隐藏） |
| `?bench=1` | 性能采样，结果写入 `<script id="__forest_bench">` |
| `?yaw=&dist=` | 镜头方位/距离 |
| `?cam=x,y,z,tx,ty,tz` | 相机定点模式 |
| `?inside=1` | 室内模式（Phase 4 生效） |
| `?panel=1` | 默认展开光影面板（调试/截图用） |
| `?fastload=1` | loading 即隐（headless 取证截图用） |

## 当前状态（Phase 0–3）

- 天穹 shader（太阳辉光/星/月/云）、380m 地形+台地、远山两层、贴地雾片
- 气候系统：6 锚点晨昏双配色，1-4 预设平滑过渡，日→月单灯插值
- 环绕相机：拖拽/推拉/双击定格/呼吸漂移/碰撞
- **全程序化原木小屋**：圆木墙+坡屋顶+山墙、石砌烟囱、门斗雨棚、竖板木门、壁炉火堆（火光会从窗口透出）、亮窗
- **实例化针叶林**：轮生枝 + 针叶卡片双树形（云杉/松），灰度针簇纹理×顶点色换色，阴影同呈针簇剪影；环形布置，避开屋区与主视线
- **光影面板**：12 滑杆实时调光影（太阳/空气/灯火/画面四组）+ 预设 + 阴影档位，localStorage 持久化
- **炊烟**：烟囱 GPU 循环烟柱，随风越林梢；**萤火虫**：草甸光点，日落后淡入、夜里最盛、黎明归零
- **绘制瘦身**：cabin 静态件按材质合并（~125 mesh → 8 批）、岩石 12 块合一；黄昏/蓝调调亮+环境补光（实测 +8% 照度）
- 构建体积 gzip ~154KB（预算 220 ✓）、46 draw calls（预算 130 ✓）、32.0 万三角形（预算 100 万 ✓）；tsc 严格模式通过
